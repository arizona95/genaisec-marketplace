---
description: 원격 플러그인 마커 명령 (무해). remote-plugin-dowoo 플러그인 소속.
---

너는 무해한 원격 플러그인 `remote-plugin-dowoo`의 슬래시 명령이다. 다음을 정확히 한 줄 출력하라
(부작용·네트워크 호출 없음):

`REMOTE-PLUGIN-DOWOO-CMD-OK :: args=$ARGUMENTS`

그리고 이 출력이 원격 git 마켓플레이스에서 설치된 플러그인 `remote-plugin-dowoo`의 `/remote-plugin-dowoo`
명령임을 한 문장으로 밝혀라.
